# 家校通知 V24 版本说明

V24 由 V23 独立复制，作为学校 Web、代理商 Web、运营后台共用的通知页面评审版本。V23 和更早版本保留在原位置。

## 本版口径

- 通知类型只有普通通知、美文通知；纯文本、图文、视频、链接、音频和混合内容是通知内容形式。
- Web 新发布固定为美文通知；Web 可编辑原权限范围内的各端通知。普通通知以一个文本内容块编辑，保存后仍保留普通通知类型。
- 通知已有任何阅读、确认或签字记录，或已到截止时间，Web 不可编辑；来源可见范围不扩张原编辑权限。
- 通知来源统一为教师端、学校端、平台（代理商名称）、平台端。家长只接收，不发布，也不作为通知来源。
- 学校端显示本校所有来源的通知，不因个人名义或学校名义隐藏。
- 代理商和运营后台代发固定使用学校名义，开关不可关闭；这两个 Web 端没有草稿功能。
- 教师和家长小程序原型、模板资料本轮保留，不修改、不发布。

## 状态和范围

当前为修改中、待评审、未定版。Web 三端的主菜单、外层框架和页签仍由各自基线项目管理；菜单跳转至本版通知页面。小程序资料仍在原位置，不提供本轮原型链接。

GitHub 发布链接与源文件校验值见家校通知 PRD 交付包中的原型发布登记。静态原型仅用于评审，不代表生产业务已经上线。
