# 家校通知 V25 版本说明

V25 由 V24 复制，作为学校 Web、代理商 Web、运营后台共用的通知页面评审版本。V24 和更早版本保留在原位置。

## 本版口径

- 通知类型只有普通通知、美文通知；纯文本、图文、视频、链接、音频和混合内容是通知内容形式。
- Web 新发布固定为美文通知；Web 可编辑原权限范围内的各端通知。普通通知以一个文本内容块编辑，保存后仍保留普通通知类型。
- 通知已有任何阅读、确认或签字记录，或已到截止时间，Web 不可编辑；来源可见范围不扩张原编辑权限。
- 通知来源统一为教师端、学校端、平台（代理商名称）、平台端。家长只接收，不发布，也不作为通知来源。
- 学校端显示本校所有来源的通知，不因个人名义或学校名义隐藏。
- 代理商和运营后台代发固定使用学校名义，开关不可关闭；这两个 Web 端没有草稿功能。
- 教师和家长小程序原型、模板资料本轮保留，不修改、不发布。

## 状态和范围

当前为修改中、待评审、未定版。Web 三端的主菜单、外层框架和页签仍由各自基线项目管理；菜单跳转至本版通知页面。小程序资料仍在原位置，不提供本轮原型链接。

GitHub 发布链接与源文件校验值见家校通知 PRD 交付包中的原型发布登记。静态原型仅用于评审，不代表生产业务已经上线。
## V25 界面调整

- 通知来源筛选按学校端、教师端、平台端、代理商来源排列；多个代理商按现有配置顺序稳定排列。
- Web 通知内容编辑不提供录音入口。教师小程序原有录音资料保留。
- 离开未保存编辑内容时，弹窗标题为“放弃编辑”，文案为“确认放弃当前输入吗？确认后将丢失本次填写内容”，按钮为“取消”“确定”。
- Web 列表来源单行完整显示；标题最多显示10个字，超出显示省略号，悬停可查看全文；发布时间和创建时间均显示为“YYYY-MM-DD HH:mm”。
- 代理商、运营后台的列表按钮统一显示“代发通知”。
- 运营后台当前基线菜单 v0.70 的“家校通知”入口指向 V25 通知功能。
- 三端列表操作名称统一为“预览”。预览页标题统一为“通知预览”；页面仅显示通知信息，不显示查收统计；通知信息区域可单独滚动，标题保持固定。
- Web 学生统计改为班级汇总 A 页和班级学生明细 B 页；教师统计仍按教师名单展示。两个统计页签均不显示提醒按钮。A 页按年级、班级筛选，班级选项显示年级和班级；进入 B 页后 A 页筛选值保留。B 页只按状态和学生姓名筛选；指标、筛选联动、分页、空结果和异常口径详见 V0.8 PRD。
- 有删除权限的记录点击“删除”均显示删除确认弹窗；无权限示例记录的按钮保留“删除”文字并置灰，悬停提示“无权限”。
- 已有人阅读、确认或签字的通知，编辑按钮置灰，悬停提示“已有人查收，不可编辑”；最后一条无操作权限示例记录的编辑按钮置灰，悬停提示“无操作权限”。无删除权限记录的按钮文字保留“删除”并置灰，悬停提示“无权限”。

## 版本范围

本版只修改 Web 共享通知页面、三份 Web PRD、全端共通规则、PRD 映射与发布登记，并将运营后台 v0.70 的家校通知菜单接入 V25。教师与家长小程序原型和模板资料继续保留，不单独修改或发布。



## 本轮列表范围与人数显示

- 代理商列表只显示本代理商成员代发的通知；同一代理商成员共享本代理商全部成员的记录。列表不显示通知来源筛选或来源列，显示目标学校，并在创建时间后显示发布时记录的操作人姓名快照。
- 运营后台列表显示所有学校、所有发布人和来源的通知。跨出当前账号原有管理范围的记录可预览和查看统计；编辑、删除继续按原有权限置灰。
- 学校 Web 显示发给当前学校的全部来源通知。
- 三个 Web 列表的未读和已读人数始终显示数字；已确认人数仅在“需确认收到”时显示数字，已签字人数仅在“需签字确认”时显示数字；不适用的列显示“--”。
- Web 通知列表中，“通知标题”表头居中显示，标题内容靠左显示；三端使用同一规则。
- 三端 Web 列表“发布人”表头改为“发布名义”；展示仍按学校名义显示学校名称、个人名义显示教师姓名。
- 代理商根目录菜单与 v0.66 基线菜单均进入 V25；发布时间和创建时间完整显示年月日及小时分钟。
- 三个 Web 端筛选栏均不提供“内容形式”筛选；通知类型、正文内容素材和编辑方式不变。
