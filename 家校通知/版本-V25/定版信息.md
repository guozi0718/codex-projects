# 家校通知功能源 V25

来源：V24。V25 是学校 Web、代理商 Web、运营后台共用的评审版本；状态为修改中、待评审、未定版。

## 已确认口径

1. 通知类型只有普通通知和美文通知；链接是正文内容形式，不是单独通知类型。
2. Web 新发布固定为美文通知；符合原权限范围的普通通知可以编辑，正文按一个文本内容块显示，保存后仍保留普通通知类型。
3. Web 可以编辑符合原权限范围的各端通知；只要已有任何阅读、确认或签字记录，或已经到截止时间，就不能编辑。
4. 通知来源只有教师端、学校端、平台（代理商名称）、平台端。家长端只接收、不发布、不作为来源。
5. 学校 Web 可查看本校各来源的所有通知，不区分个人名义或学校名义；原编辑权限范围不变。
6. 代理商和运营后台代发通知时，必须使用学校名义，开关固定开启且不可关闭。
7. 代理商 Web 与运营后台当前不提供草稿；小程序原型及模板资料保留，本轮不修改、不发布。

## 继承与待确认项

V25 沿用 V24 的正文编辑器、附件、全文背景、统计分页和打印预览等页面设计；学校 Web 和运营后台的发布对象沿用各自名单选择方式，代理商端新建通知改为全体学生/全体教师下拉多选。V25 学生统计另采用班级汇总 A 页与班级学生明细 B 页：A 页展示年级、班级、统计进度和明细，B 页仅保留状态及学生姓名筛选；教师统计保持名单视图，三个 Web 端统计页均不提供提醒按钮。具体规则与异常场景见当前 V0.12 Web PRD与共通规则；小程序 PRD 仍保留 V0.10。全年级选择后新增班级是否加入原通知（Q70）、代发过程中改选学校后的内容和发布对象处理方式（Q71）仍待确认，本文不替用户决定。

## 对应资料

六份 PRD 与索引、映射规则、核对记录和发布登记位于任务 T-20261118-03 的交付目录，当前 Web PRD 与共通规则批次 V0.12；小程序 PRD 仍保留 V0.10。Web 基线菜单入口和 V25 通知页面链接以 PRD 交付索引为准。

本版只用于交互评审，不代表真实账号授权、名单、消息提醒、数据归档或 PDF 服务已经上线。
## V25 批注落实

通知来源筛选顺序、单行来源显示、标题10字省略和悬停全文、创建时间格式、Web移除录音入口、未保存离开弹窗、统计页移除未读提醒按钮、预览页标题统一为“通知预览”且不显示查收统计、列表操作改为“预览”、查收后不可编辑及无权限按钮提示，均已写入共享原型及相应 Web PRD。Q70、Q71仍待确认。

## V25 本轮追加口径

- 代理商按代理商机构共享代发通知；操作人列保留发布时姓名快照。代理商列表不展示通知来源筛选或来源列。
- 运营后台可查看所有学校通知，但原有发布、编辑和删除权限不扩大。
- 三个 Web 列表的确认、签字统计列按查收方式显示数字或“--”。
- 三端 Web 通知列表的“通知标题”表头居中，标题内容靠左，其他字段内容居中。
- 三端 Web 列表“发布人”表头改为“发布名义”；显示值保持学校名义对应学校名称、个人名义对应教师姓名。
- 代理商根目录菜单与 v0.75 基线菜单均进入 V25；发布时间和创建时间完整显示年月日及小时分钟。
- 三个 Web 端筛选栏均不提供“内容形式”筛选；通知类型、正文内容素材和编辑方式不变。
- 学校端和运营后台列表在创建时间后增加操作人字段；学校端显示姓名并悬停查看老师端、学校端、平台端或平台（代理商名称快照），运营后台显示姓名及角色。代理商端既有操作人姓名快照列保持不变。

## V25 本轮交互修订

- 代理商新建代发通知仅能选择全体学生、全体教师，可单选或同时选择；不支持按年级、班级或个人选择。复制已有通知时清空旧对象并重新选择。
- 三个 Web 端 PC 发布设置页统一为字段名称与控件同一行，各行对齐且控件高度一致；窄屏允许纵向排版。
- 新规则已同步四份共通/ Web PRD、发布登记和交付索引；文档仍为修改中、待评审、未定版。
## V0.10 本轮修订

- 三个 Web 通知列表移除“发布人”筛选；运营后台和代理商端增加“目标学校”首位模糊筛选及可见学校候选回显。
- 代理商列表操作只显示“预览”“编辑”，隐藏“删除”“阅读统计”。
- 三端 Web 的“以学校名义通知”和“定时发送”调整为非必填；学校端默认学校名义，显示学校名称或当前登录人姓名快照；代理商和运营后台固定以学校名义发送。
- Web 及小程序预览标题居中显示，长标题完整换行。


## V0.11 普通通知 Web 编辑修订

学校 Web、代理商 Web、运营后台编辑普通通知时，只显示唯一文本块；不显示新增内容块入口，也不提供上移、下移和删除按钮。文本及文字格式可编辑，保存后仍为普通通知。美文通知编辑方式不变；小程序原型与模板资料不修改。


## V0.12 Web 通知预览

三个 Web 端的通知预览使用小程序样式手机边框，内容区独立滚动；预览只读。打印和 PDF 维持独立 A4 版式，不将手机边框、模拟状态栏和页面按钮导出。小程序页面与模板资料不因本项调整。
