# 运营后台候选 v0.75 版本说明

## 变更内容

- 家长资料页统一使用完整资料页框架，适用于有订单和无订单的家长账号。
- 基本信息固定展示家长姓名、家长ID、手机号、注册时间、注册方式、关联学校、最近登录时间、最近反馈时间；暂无来源值时显示“--”，不生成演示数据填充真实资料字段。
- 基本信息页保留关联孩子、累计订单、退款申请、问题反馈统计卡及孩子信息区。
- 手机号仍按现有规则显示脱敏号码；移除“完整号码查看需接入平台敏感信息权限”提示。
- 订单、退款、反馈内容仍按当前家长账号关联；各页签始终展示“订单信息”“退款信息”“反馈信息”标题，无对应记录时分别显示“暂无对应数据”。
- 左侧查询结果中的家长摘要同步显示关联孩子、关联学校和最近登录时间，字段与完整资料保持一致。

## 继承范围

运营回复弹窗、回复成功自动通知、用户查询入口、四个资料页签、账号记录关联范围和其他后台页面继承 v0.74，不在本版扩大修改。

## 状态

GitHub 静态评审候选；第一期修改中、未定版；活动版本指针不变；不代表生产系统。此版本只按本轮批注调整家长资料页空状态文案及手机号旁提示。
