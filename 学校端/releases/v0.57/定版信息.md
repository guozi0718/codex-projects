# 家校通知功能源 V22

V22 从 V21 复制并在独立目录修改。状态为第一期新增、修改中、待评审、未定版。Web 三端共用此通知页面；教师和家长小程序的界面与模板资料继续保留原样。

## 本轮四项批注

1. **删除后留档**：普通通知列表及教师、家长接收页不再显示已删除通知；不显示“已删除”状态，不提供已删除列表或恢复入口。隐藏快照保留删除时的完整通知资料，包括通知内容、封面、附件、发布设置、发布对象、个人阅读/确认/签字记录、操作人和删除时间。留档暂由原型本地数据模拟。
2. **截止时间默认空**：新建通知的截止时间不预填日期；用户未设置时始终显示为空，通知仍按发送后30个自然日的有效期规则处理。
3. **提醒仅面向未读对象**：Web 学生统计仅对汇总未读学生展示提醒，并提醒该学生所有关联家长；学生已读但尚未确认或签字时不提醒。教师统计仅对未读教师展示提醒。无未读对象时不显示提醒按钮；提醒不显示逐人发送任务状态，失败不自动重试。
4. **发布状态顺序**：筛选顺序为“全部、待发送、已发送、已截止”。V21 已符合此顺序，V22 复核后保留；不增加草稿、已删除或已撤回状态。

## 保持不变

- 学校 Web 两步发布；代理商 Web 和运营后台三步发布。
- 正文全文背景、通知列表和统计字段、筛选项、操作按钮、菜单归属和各端页面框架沿用 V21。
- 教师和家长小程序页面、提醒界面及通知模板不在本轮修改范围内；V22 中教师小程序沿用原提醒交互。
- 编辑后有效期如何重新计算、已经设置的截止时间如何处理等 Q66–Q68 仍待确认，不以本轮原型改动代替确认。

## 评审文件

- `index.html`：V22 页面入口及静态资源版本标识。
- `app.js`：Web 端未读提醒入口、删除后的列表显示、截止时间字段交互。
- `core.js`：空截止时间、未读提醒范围、删除快照及旧本地演示数据迁移。
- `styles.css`：统计页面提醒操作区样式。
