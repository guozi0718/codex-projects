## 1. 范围

本文仅覆盖家长小程序反馈提交、详情时间线及相关校验。教师小程序有单独文件。完整小程序入口与活动基线由小程序主项目管理。

## 2. 已确认规则

1. 家长反馈、追问以及任何已发出的回复消息提交后都不可修改。
2. 不提供已提交消息的修改按钮、编辑页、编辑路由或消息修改接口；模型不得写入已提交消息的新版本，不展示历史修改版本、修改时间或“已修改”标记。撤回/删除按状态标注并保留消息原文、附件快照。
3. 表单在提交前可编辑。取消或返回时，若存在未提交内容或附件，展示二次确认；选择继续则留在当前页面并保留输入，确认返回后清空本次未提交表单并返回上一页。
4. 家长提交时记录当前登录角色、当前家长身份，以及本次选择/关联孩子的提交时快照。仅当当前孩子状态为“在读”允许提交；离校/毕业或状态无法确认时拦截并说明原因。
5. 提交时再次核验家长身份、当前孩子的在读状态、学校/孩子关联、文本和附件；状态在打开表单后变化也必须阻止提交，并保留表单和附件供复制。
6. 家长小程序详情仅展示反馈沟通时间线，不增加独立操作日志页。首条反馈及每次追问作为独立消息；状态与附件随各自消息显示。
7. 图片附件统一最多9张；图片格式和单张大小按 Web 已确认规则：JPEG/JPG/PNG，每张不超过10MB。
8. 提交成功后正文、附件、作者、关联孩子快照及原提交时间保持不变。后续补充只能另发新消息，不覆盖原消息。

## 3. 异常与恢复

| 场景 | 处理 |
|---|---|
| 孩子已离校/毕业 | 阻止提交，提示当前孩子非在读；保留页面与已填写内容 |
| 学生状态服务异常或无法确认 | 不按在读放行；提示稍后重试并保留表单 |
| 未选孩子/孩子关系不属于当前家长 | 阻止提交并提示，保留表单 |
| 正文空白/超长 | 阻止提交并定位字段；已有附件保留 |
| 附件超过9张、格式不符、单张超过10MB或读取失败 | 提示具体原因；移除无效附件前保留其他输入 |
| 提交时身份、学校或版本失效 | 阻止提交，保留文字与附件以便复制/重试 |
| 返回或关闭未提交表单 | 二次确认；取消确认留在当前表单，确认放弃后清空并返回 |
| 试图进入未提供的修改路径 | 不创建编辑界面或修改路由；不写入数据，原始消息与附件保持 |

## 4. 页面验收

- 详情只显示时间线，不出现修改按钮、修改表单或保存修改按钮。
- 家长选择在读孩子可按既有表单规则提交，关联孩子快照固定。
- 非在读或身份不匹配时无法通过重复点击、刷新或直接触发提交绕过校验。
- 任意校验错误都不把用户踢出当前表单，不清空正文和其他有效附件。
- 放弃未提交内容必须经过二次确认；已提交消息不受返回操作影响。

## 5. 文档状态

本补充替代旧候选中的“家长可以修改最近消息”规则。仍为第一期修改稿，尚未定版；不改变小程序生产基线。

补充：家长/教师小程序的反馈详情时间线仅展示原始消息与对应附件；撤回后原消息和附件继续展示，并在首条消息旁标注“已撤回”，同时追加撤回事件。本期不创建或展示任何历史编辑版本、修改时间或“已修改”标识；撤回/删除只记录对应状态事件，原消息与附件仍显示。
