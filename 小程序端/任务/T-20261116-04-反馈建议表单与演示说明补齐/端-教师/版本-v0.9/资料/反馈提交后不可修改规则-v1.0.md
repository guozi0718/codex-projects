# 教师小程序反馈功能补充：提交后不可修改

## 1. 范围

本文仅覆盖教师小程序反馈提交、详情时间线及相关校验。家长小程序单独编写。完整小程序入口和活动基线由小程序主项目管理。

## 2. 已确认规则

1. 教师反馈、追问及任何已发出的回复消息提交后都不可修改。
2. 不提供已提交消息的修改按钮、编辑页、编辑路由或消息修改接口；模型不得写入已提交消息的新版本，不展示历史修改版本、修改时间或“已修改”标记。撤回/删除按状态标注并保留消息原文、附件快照。
3. 表单发送前可编辑。关闭/返回遇到未提交文字或附件时先二次确认；取消确认保留页面和输入，确认放弃后清空当前未提交表单并返回上一页。
4. 教师提交时自动记录当前登录角色、教师身份和当前任职学校快照，不允许手工切换为其他角色或学校。
5. 只有教师当前状态为“在职”时可提交。离职、非在职或状态无法确认时拦截并提示原因；提交时再次校验教师身份、状态及任职学校关联。
6. 教师端详情仅展示反馈时间线，不额外增加操作日志页面。
7. 图片附件最多9张；图片格式JPEG/JPG/PNG，每张不超过10MB。
8. 提交成功后正文、附件、身份和任职学校快照及原提交时间固定。需要补充内容时另发新消息，不覆盖旧消息。

## 3. 异常与恢复

| 场景 | 处理 |
|---|---|
| 教师离职或非在职 | 阻止提交，提示教师状态原因；保留当前页、文字和附件 |
| 在职状态或任职学校无法确认 | 不按在职放行；提示稍后重试，不清空表单 |
| 教师身份无效或学校关联不匹配 | 阻止提交，保留已填内容 |
| 正文空白/超长 | 定位字段提示并保留附件 |
| 附件数量、格式、大小不合法或读取失败 | 显示具体错误，其他有效输入保留 |
| 提交时状态或版本变化 | 复验失败后阻止写入，保留草稿 |
| 返回、关闭或切换页面 | 对未提交数据二次确认；取消保留，确认放弃后清空并返回 |
| 试图进入未提供的修改路径 | 不创建编辑界面或修改路由；不写入数据，原始消息与附件保持 |

## 4. 页面验收

- 教师详情仅有时间线，没有修改按钮和保存修改流程。
- 在职教师可用当前任职学校身份提交；离职或状态未知不可提交。
- 所有异常校验后仍留在原表单，正文和有效附件保持。
- 放弃草稿需二次确认；已提交消息始终只读。

## 5. 文档状态

本补充替代旧候选“教师可修改最近消息”规则。仍为第一期修改稿，尚未定版；不改变小程序生产基线。

补充：家长/教师小程序的反馈详情时间线仅展示原始消息与对应附件；撤回后原消息和附件继续展示，并在首条消息旁标注“已撤回”，同时追加撤回事件。本期不创建或展示任何历史编辑版本、修改时间或“已修改”标识；撤回/删除只记录对应状态事件，原消息与附件仍显示。
