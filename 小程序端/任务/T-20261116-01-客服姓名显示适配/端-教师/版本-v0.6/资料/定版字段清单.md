#  v0.6 定版字段清单

页面：帮助与反馈（sc-help）
状态：候选，待用户评审。

- FAQ区域：同一套 7 条 Web 配置回显；首次进入默认全部收起，点击单条展开/收起。
- 联系电话区域：单客服显示号码及工作时间，点击模拟拨号；多客服隐藏号码及工作时间，点击打开客服弹层。
- 客服弹层：按代理商客服、平台客服分组；没有客服的组不展示；每行显示姓名、号码、工作时间与“拨打”按钮。
- 客服姓名：最多 50 字完整回显；多行换行；不覆盖号码、工作时间或拨打按钮。
- 查询：小程序没有客服姓名搜索框；模糊匹配由管理端完成后回显匹配数据。
- 演示操作：页内提供单客服、多客服和 50 字长姓名预览；长姓名测试值只存在于当前页内存，刷新恢复正常示例。
- 在线客服：隐藏；“我的”Tab、反馈流程、角色隔离和其他页面均继承 v0.5。
