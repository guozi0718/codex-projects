# 教师/家长反馈详情演示说明

适用版本：教师、家长 v0.8 评审候选。页面入口在“我的反馈”，点击列表卡片直接进入该反馈详情；待回复、已回复、已撤回三条样例也可从本页演示说明直接打开。

## 查看详情

- 展示反馈编号（唯一记录ID）、状态、类型、提交时间、首条完整正文、图片、后续沟通消息、消息时间和附件。
- 不展示学校/学生快照；后端记录仍可按字段契约保留提交时上下文，但页面只呈现业务内容与处理消息。
- 时间线可查看处理方回复和本人追问。本人最近一条仍满足既有修改条件的消息显示“修改本条消息”；历史版本正文/附件仍可展开查看。编辑能力沿用上一候选逻辑，本轮不改变其权限条件。

## 撤回

1. 仅状态为“待回复”、且没有任何处理方回复时显示“撤回反馈”。
2. 点击后先出现二次确认弹窗；撤回原因选填。
3. 确认后保留原编号、正文、附件与审计历史，状态变为“已撤回”；详情保留历史但变为只读，不再允许追问或撤回。
4. 有处理方回复或已撤回的记录不显示撤回操作。服务端必须在提交时再次检查状态、回复事实及记录版本，不能依赖前端隐藏按钮。

## 补充说明 / 追问

1. “待回复”记录可补充说明或催问；“已回复”记录可追问。
2. 新消息在原反馈编号下追加，不创建新反馈编号；必须填写消息内容，正文最多500字，可附最多9张图片、每张不超过10MB。
3. 待回复时追加后仍为“待回复”；已回复后追问成功，主状态回到“待回复”。原反馈创建时间不变，更新时间及消息时间更新。
4. “已撤回”记录不可继续追问。提交流程需对记录版本和当前受理关系复核，成功后按产品既有规则通知指定受理组织。

以上操作仅为浏览器离线原型模型；重载后样例重置。真实账号鉴权、事务/并发控制、编号、文件上传存储、通知与审计接口均未接入。教师和家长分别按当前角色+提交账号读取本人记录；端上不提供学校/孩子快照筛选。
