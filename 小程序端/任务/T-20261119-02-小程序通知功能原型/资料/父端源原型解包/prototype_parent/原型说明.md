# 亲小禾 · 家长端 通知模块 1:1 静态原型

- 产出时间：2026-11-18（PST）
- 目录：`prototype_parent/`（入口 `index.html`，素材 `assets/`）
- 交付包：`亲小禾_家长端_通知模块_1比1复刻.zip`
- 技术形态：**纯前端静态 HTML + 真实截图**，无任何后端、数据库、网络请求
- 采集方式：仅 `PostMessage` / `SendMessage` 向小程序渲染子窗口投递鼠标、滚轮、字符消息；`PrintWindow` 截图。全程未移动物理鼠标、未改变窗口尺寸与层级、未调用任何置顶/前置 API。
