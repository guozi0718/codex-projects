## 版本与同步

每次发布创建不可变`发布/r日期.序号/`，保留历史目录及Git提交；当前稳定入口为`教师/`、`家长/`。发布清单记录SHA-256及必要路径适配，源原型未覆盖。

仅当用户在当前会话明确要求推送时，才在完成验证、快照和管理记录后执行下列命令。任务完成、页面确认或提供链接均不自动上传：

```powershell
node "任务/T-20261117-02-GitHub发布与自动同步/工具/同步GitHub.cjs" --push
```

有新功能版本时，先按项目治理规则更新GitHub发布配置、创建新的发布编号，运行同目录`准备发布.cjs`，检查后同步。此命令只提交仓库`小程序端/`，不删除远程历史、不强制推送、不修改其他项目目录。共享仓库并发推送经fetch/rebase整合，冲突停止保留。

GitHub Pages沿仓库现有main根目录配置部署；只有用户明确授权并完成的本次提交才触发部署。没有本轮推送指令时不上传。凭据使用本机Git凭据管理器，工作区克隆不上传。

## 演示边界

HTML离线原型，演示登录/支付/客服/反馈数据不代表真实服务。保留源原型的第三方外部原型入口；通知静态依赖已随发布包提供。当前发布只做身份与通知路径适配，不改业务逻辑。
