# ADR-002：GitHub按明确授权推送

- 状态：Accepted
- 日期：2026-11-18
- 任务：T-20261118-01-明确推送后发布

## 背景
此前项目存在活动指针定时上传或任务完成后持续自动上传的规则。用户指出候选上传可能被误认为确定版本，并明确要求运营后台、代理商Web、学校Web、智小徽小程序均只在其明确说推送时上传。

## 决策
1. 只有用户在当前会话明确要求推送，才可对本项目执行GitHub上传。任务完成、候选/定版、验证通过、页面确认或要求提供链接都不自动产生上传授权。
2. 运营后台计划任务 Codex-Operations-GitHubSync 和学校端计划任务 Codex-School-GitHub-AutoPublish 停用；运营后台工具拒绝 --watch；学校auto-sync.ps1要求显式 -Push。
3. 保留不可变版本、快照、共享仓库并发保护和 Pages 部署流程。GitHub Pages可在获授权的提交后自动部署；这不构成自动上传授权，也不把候选变为业务定版。
4. 没有明确推送指令时，保持本地修改，不创建远端提交；提供链接时区分现有在线版本与本地候选。

## 影响
仅改变发布授权触发方式与相应说明，不改业务页面、活动指针、既有远端版本或候选/定版状态。此决策取代此前项目内的持续自动上传授权；历史发布记录保留。
