# ADR-001：GitHub发布与版本同步

状态：Accepted（发布技术方案，本轮明确授权）
日期：2026-11-17
任务：T-20261117-02

## 背景
用户要求完整项目进入指定仓库小程序端目录，保持版本管理、自动上传和线上原型链接。仓库已有其他项目及main根目录GitHub Pages配置。

## 决策
本项目源文件和强制快照保留；在隔离克隆中只新增/更新小程序端目录。每次发布独立不可变目录及Git提交，最终发布提交建立miniapp-r日期.序号标签；固定教师/家长入口指向当前发布。任务验证与最后日志完成后自动执行同步，推送触发仓库现有Pages构建。

## 替代方案
不在主项目根初始化/重置Git，不覆盖共享仓库根首页与其他项目；不使用保存即推送的后台监听，以免上传未验证中间状态。

## 影响
后续任务遵守GitHub发布配置与自动同步规则；已发布源版本不回写，候选/定版状态不因上线预览变化。生产API和微信原生栈仍不在HTML发布验证范围。
