# 家长端客户反馈 v0.12 候选说明

- 日期：2026-11-17
- 状态：评审候选，未定版、未发布；小程序活动基线仍为 T-20261114-01 v0.5。
- 来源：直接承接本任务家长端 v0.11（其上游为小程序主项目 T-20261116-08 v0.10）；历史版本只读保留。
- 继承范围：反馈列表整卡进入详情、移除“查看详情”并将时间右对齐；反馈编号先于类型，完整展示首条反馈内容/附件并移除独立提交时间；公开消息倒序、无后续消息时不显示空沟通卡；每条详情固定显示等宽“追问”“撤回”，不可用时置灰。
- 本轮变更：反馈类型与状态同一行、状态靠右；时间线增加首条“提交”动作并靠右显示 `MM-dd HH:mm` 提交时间；已撤回记录仍显示原始反馈内容/附件及已撤回状态，时间线样式参照学校 Web；详情按钮及提交页/追问弹窗的取消与提交按钮统一等宽、等高。
- 追问：弹窗显示原反馈完整业务内容、附件及公开沟通历史；移除额外说明；必填正文上限1000字，附件最多9张/每张≤10MB，沿原反馈编号追加，已回复后回待回复。
- 撤回：仅待回复且无处理方回复时可撤回；按学校 Web v0.43文案仅二次确认，不填写原因；撤回后保留记录/附件并置已撤回。
- 家长既有功能：保留第一期反馈入口和选孩子提交上下文；提交时由服务端复验家长身份、当前孩子关系、学校/学籍状态和 Web 资格，写入提交时快照；资格状态枚举由 Web/服务端字典映射。孩子解绑、转校、从当前孩子列表移除或原一年入口期结束，仍可查看本人历史。详情不显示学生/学校快照。
- 记录/隔离：feedbackNo是唯一记录ID兼反馈编号；状态待回复/已回复/已撤回；按当前家长角色+提交账号隔离，不按当前选择孩子过滤；同家庭其他家长不可见。
- 图片：新建反馈与追问均最多9张、每张≤10MB；JPG/JPEG/PNG；读取失败/超限/越权/状态变化按当前原型提示，不产生部分提交。
- 验证：`assets/help-v1.js` 通过 Node 语法检查；本轮双端相应资源同步；本地浏览器页面及手机框内截图已核对。真实后端、微信原生页面栈未验证。
- 截图：任务资料 `资料\截图对比\原-v0.11\`、`现-v0.12\`，均裁切至原型手机边缘，无框外桌面空白。
- 源基线及版本指针未改；待用户评审，不作为发布版本。


本版本承接教师/家长 v0.11 评审候选；本轮仅增加首条提交时间线、反馈类型与状态同行右对齐、已撤回记录保留原始反馈及撤回标记，并统一反馈页所有成对按钮尺寸。候选待评审，未定版、未发布。
