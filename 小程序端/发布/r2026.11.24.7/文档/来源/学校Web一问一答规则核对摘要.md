### 规则确认摘要

| 规则 | 确认结果 |
|---|---|
| 学校、老师、家长来源 | 代理模式由代理商直接处理；直营模式由运营后台直接处理；同一记录仅一问一答 |
| 代理商自有反馈 | 由运营后台处理；不限轮数，但严格一问一答交替 |
| 下一条消息 | 只能由当前等待的一方发送；等待答复期间不得连续发问或回复 |
| 排序 | 列表按记录最后更新时间倒序；详情时间线按消息时间倒序 |
| 修改 | 所有已提交反馈与回复均不可以修改 |
| 删除/撤回 | 均移除，不显示相关按钮或状态标记 |
| 抄送/转达 | 本版移除，不展示协作块或转达来源关系 |
| 通知 | 主动发起并记操作；不显示送达状态，不自动重试 |
| GitHub | 当前版本为本地候选；尚未推送 |

本文件只摘录 Web 端共用业务边界；三端页面字段、操作及异常分别写入三份端内 PRD，不混合小程序逻辑。
