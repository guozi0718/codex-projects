# 系统字段管理产品需求文档

需求阶段：第一期新增功能  
适用端：运营后台 Web 端（唯一管理端）；配置结果影响监管多端、学校端、教师小程序、家长小程序、电子班牌。  
产品负责人：【待确认：负责人姓名】  
文档状态：修改中，未定版。  
主入口：运营后台“系统设置 → 系统字段管理”。本文件只定义系统字段管理页面及其业务交互；运营后台其他页面不在本需求范围内。

## 1. 需求背景

现有业务通过“客户管理 → 合同管理”创建监管、学校账号，需要由运营人员为已开通的机构设置预定义替换字段。现有机构树把行政层级和生效范围放在一起，“全选下级”容易导致误选。系统字段管理位于“运营后台 → 系统设置”主菜单，排在“承运商管理”之前；菜单、页面展示与权限由运营后台项目统一管理。配置仍通过监管机构、学校两个页签明确选择，合同只负责定位已开通机构，配置绑定机构 ID，不绑定合同、行政区划或个人登录账号。

## 3. 文档说明

### 3.1 名词解释

| 名词 | 说明 |
|---|---|
| 已开通机构 | 现有账号开通流程实际建立的监管组织或学校租户。按稳定机构 ID 标识，同名机构不合并；同机构多个登录账号不重复配置。不是全国行政区划字典。 |
| 监管机构 | 已开通监管端的监管组织。选择一个只作用于该监管机构，不自动包含下级监管机构或学校。监管端展示数据按本PRD 6.6 的单校/跨校口径取配置。 |
| 学校 | 已开通的学校机构。学校配置按学校机构ID提供给学校端、教师小程序、家长小程序、电子班牌等已确认影响端读取；不是分别选择个人账号。 |
| 一条配置 | 一个字段类型、一套系统字段到替换字段的映射、一个或多个机构ID组成的记录。七个系统字段只能作为整体统一选择“全部替换为“学生终端” / 全部替换为“学生卡” / 全部恢复默认”，不支持逐字段修改或部分恢复；同一字段类型+机构ID最多由一条含替换值的记录占用。全字段恢复默认后记录保留但释放占用，后续允许新增；恢复行与新配置分开显示，历史日志按原配置ID追加。 |
| 合同定位 | 在适用机构弹窗中选择合同名称以筛选候选机构；展示名称，内部用稳定合同ID匹配机构关联。合同筛选不改变配置唯一键，续约、到期或解除该合同与机构的关联均不改变既有配置；只要机构仍正常开通，配置继续生效，配置独立绑定机构ID。 |
| 恢复默认 | 仅对七个系统字段整体使用系统原词，不表示删除字段，也不继承上级配置。现行表单不提供单字段恢复默认。既有配置全部恢复默认时，按当前表单范围恢复系统原词；配置记录保留、不停用、不删除，释放同字段机构占用，更新最后操作人和时间并将恢复记入原配置日志；新建全部恢复默认不允许保存。 |

### 3.2 编写与实现边界

采用资料库“当前 GitHub 主分支版-20261013”的通用 PRD 模板：按页面编写，字段一行一项，提示、校验、异常跟随对应字段和按钮，不另设提示汇总。参考关爱学校端定稿的权限、并发、数据状态和返回规则；冲突时采用较新的模板要求。

运营后台本机评审页面中的机构、客户、合同均为演示数据。

第一期业务规则见3.3；本文档以当前确认口径描述，不记录产品讨论轮次。

### 3.3 第一期业务规则

| 主题 | 第一期规则 |
|---|---|
| 管理端和菜单 | 仅运营后台提供系统字段管理页面，菜单为“系统设置 → 系统字段管理”，排在“承运商管理”前。学校端、监管端、教师小程序、家长小程序、电子班牌不提供管理页面或管理操作。 |
| 影响端与读取 | 配置结果影响监管多端、学校端、教师小程序、家长小程序和电子班牌；保存后更新配置，端侧下次打开或刷新读取新结果。管理页面不呈现端侧生效状态。 |
| 系统字段映射 | 七项系统字段作为整体处理，只能统一替换为“学生终端”、统一替换为“学生卡”或全部“恢复默认”；字段行只读展示结果，不支持单项编辑、混用或局部恢复。 |
| 适用机构范围 | 监管机构只作用于本机构，不自动包含下级；学校按学校机构ID作用于该校关联的影响端。每条配置至少包含一个机构，机构数量不设产品上限，候选范围受当前账号授权范围限制。 |
| 监管端取词 | 单校业务数据按对应学校配置取词；跨校汇总按监管机构配置取词。 |
| 配置唯一性 | 以字段类型和机构ID校验。同字段类型、同机构被其他有效映射占用时，整条保存阻断并列出冲突机构；不同字段类型互不冲突。全部恢复默认后释放占用，保留原记录ID和日志；同机构后续新增记录分行显示。 |
| 恢复默认 | 编辑既有配置并选择“恢复默认”后需二次确认所选机构将展示系统字段且配置记录保留；按当前编辑范围恢复系统原词，保留原记录和日志、释放占用，并更新最后修改人和时间。恢复记录仍可编辑；重新启用映射时重新校验占用。 |
| 范围变化 | 编辑后移出部分机构，只有保存成功才使移出机构恢复系统原词，范围内其他机构继续应用配置；范围为空时禁止保存。 |
| 合同关系 | 合同仅用于定位可选机构；配置独立绑定机构ID。合同到期、解除或变化不改已存配置；机构停用或启用也不改变配置。 |
| 日志和操作者 | 只记录成功新增、修改、恢复默认；记录修改前后映射与范围、操作者ID、操作时名称快照和时间。失败、取消、无改动不记，留存按运营后台平台规则。 |
| 保存与执行顺序 | 管理端保存失败不改变原配置；结果未知时使用原请求ID查询，禁止重复提交。配置连续保存按提交顺序执行，旧配置先于新配置；不提供端侧状态、产品侧失败重试或回滚。 |
| 系统字段位置清单 | 各端受影响的实际字段位置按用户提供的清单确定；产品不增加“缺字段”提示或回退分支。 |

以上为第一期当前业务口径。运营后台主菜单与本页面已在本机评审环境联动；本机示例数据不连接生产权限、真实接口、持久化或跨端分发。

#### 6.1.2 查询条件

| 条件 | 控件 | 必填 | 默认值 | 数据来源与枚举 | 规则、提示与异常 |
|---|---|---|---|---|---|
| 筛选布局 | 条件标签与控件 | — | — | 参照运营后台合同管理筛选行 | 标签文字右对齐，标签列96px、与控件间距10px；桌面端输入框和字段类型下拉框宽270px、高32px、14px字号、4px圆角，查询/重置按钮高32px、4px圆角，操作按钮靠筛选区右侧。视口宽度不大于1100px时条件改双列、操作按钮另起一行靠右；不大于560px时单列，标签列96px、控件自适应。控件不得挤压重叠；不改变查询应用时机、Enter查询或筛选条件。 |
| 字段类型 | 单选 | 否 | 全部 | 全部、校徽类；研发维护可用类型 | 不级联机构名；与机构名同时满足。选择后点查询生效。未来增加类型应联动预设字段/选项/适用机构，不能让运营自行新增字典；未来类型不在本期原型里虚构。字典读取失败正式禁用新增并允许重试，不能用过期枚举提交；原型字典固定。 |
| 适用机构 | 文本框 | 否 | 空；请输入机构名称 | 当前授权配置的机构名称 | 最多50个字符，包含边界，原型按浏览器maxlength计数；输入/粘贴超长不接收多余内容，查询时去首尾空白。按名称包含匹配；一条配置的任一已选机构符合即命中。不是按行政上级名称扩展。Enter或查询生效；无结果显示空列表，不改变已有业务记录。条件不级联。正式Unicode字数口径须与前端一致。 |
| 查询 | 主按钮 | 否 | 可点 | 当前两项条件 | 点击查询回第1页；加载中显示“加载中，请稍候”，不显示总数为0；查询成功空结果显示“暂无符合筛选条件的记录”，总数0。失败在查询区红字“网络异常，请稍后重试。保留上次成功结果，请重新查询。”保留旧结果，不冒充新查询结果；可更改条件或重试。正式请求采用最新请求结果，过期响应不能覆盖新条件。原型绿点“加载中”保持等待，切回正常再查询。 |
| 重置 | 次按钮 | 否 | 可点 | 不读取用户业务输入 | 类型恢复全部、机构名清空、页码1，立即查询；没有筛选变化也可点，不清空配置。失败保留上次成功列表并显示查询失败文字；用户仍可重新查询。 |

#### 6.1.3 列表、分页与操作

| 字段 / 区域 | 数据来源 | 显示格式 | 规则、交互、提示与异常 |
|---|---|---|---|
| 序号 | 当前页与页大小 | 正整数，起始为(页码-1)×页大小+1 | 列表序号列约56px，按合同管理紧凑表格布局。窄视口仅表格横向滚动；序号不是记录ID，不作为任何操作主键。 |
| 字段类型 | 保存记录type | 校徽类 | 空或字典异常正式显示“--”，禁用编辑并提示“字段选项已更新，请返回列表后重新打开。当前填写保留供核对”。原型仅提供固定校徽类。 |
| 系统字段 | 本记录有替换值的系统字段 | 首两项同一行展示；其他字段及总项数可悬浮查看 | 按七词固定顺序：智能校徽、佩戴校徽、校徽绑定、校徽管理、校徽办理二维码、分享校徽办理、校徽卡面；窄屏表格横向滚动。所有有效配置均由七个字段整体映射；全默认恢复记录在本列显示“系统字段”，不删除、不停用，继续以原配置ID留在列表。

### 6.6 跨端生效与服务端验收边界

此节说明配置保存、范围变更、连续变更顺序与服务端验收边界。系统字段管理只有运营后台管理页；监管多端、学校端、教师小程序、家长小程序、电子班牌是字段结果的影响端，不提供本管理操作，也不在本页面展示端侧应用状态。

| 字段 / 场景 | 数据来源与规则 | 交互、异常与验收结果 |
|---|---|---|
| 配置唯一性 | 字段类型+机构ID；仅全局映射为学生终端或学生卡时占用 | 保存全局映射为学生终端/学生卡时，逐一复核所有机构；任一同字段类型机构已被另一条有效记录占用，整条保存失败并按用户文案提示。不同字段类型互不冲突。全部恢复默认时释放占用但保留原记录和日志；允许同机构新增另一条独立记录。恢复记录再次启用映射时按当前适用范围重新校验；冲突时保留恢复状态与草稿，不覆盖新配置。
| 替换定位 | 研发预设展示文案键与用户提供的各端字段位置清单 | 只对清单登记的位置应用映射。不对数据库原始文本进行全局字符串替换，不改历史合同、用户自由输入、附件、已发消息、账号ID及设备序列号。包含词如智能校徽与校徽分别按文案键映射，不能先替换短词破坏长句。恢复默认回系统字段；学校关联端通过当前业务学校ID取规则，不能用家长个人账号的上次学校缓存。未纳入用户清单的位置不宣称已覆盖。 |
| 监管与学校数据口径 | 单位取值依据稳定机构ID | 监管选择不扩展至下级。监管端展示单所学校业务数据时按该学校机构ID读取学校配置；跨校汇总按当前监管机构ID读取监管配置。教师多校、家长多孩、班牌切换学校时按当前业务学校ID取配置，避免跨租户串用。无本机构配置时展示系统原词（按恢复默认语义推导）；实际展示位置以用户提供清单为范围。 |
| 配置保存与端侧应用顺序 | 配置以机构ID独立绑定；多次变更按提交顺序串行应用 | 管理端保存失败时不改变原配置、机构范围、最后修改人/时间或日志；草稿保留。业务保存成功即更新配置与成功日志，只提示“保存成功”。若同一配置连续保存，旧配置先执行，新配置后执行，最终使用最新值；本PRD不设置端侧失败、自动/手动重试、回滚或状态展示分支。
| 不回滚 | 已确认不提供产品侧回滚。 | 无回滚按钮、确认、状态或回退请求；连续变更按顺序执行。
| 机构范围调整与全局恢复默认 | 适用机构范围可增删；替换方式只能整组设置七字段 | 局部移出的是机构范围调整：保存成功后被移出机构恢复系统原词，其余所选机构继续应用本次整组映射。替换字段不支持逐字段或部分恢复。既有配置选择“全部恢复默认”时，按当前编辑范围恢复系统原词，原记录保留并释放占用、更新范围和最后修改人/时间，日志仍按原配置ID追加；列表仍显示“适用范围”。恢复记录与新配置分行，重新启用时按字段类型+机构ID重新校验占用。
| 合同关联变化 | 合同只用于筛选/定位机构；配置以机构ID独立绑定 | 合同续约、到期、解除或删除合同关联时，只要机构仍正常开通，已有字段配置继续生效，原配置不因合同关联变化而停用、删除或改绑。合同筛选变化只影响候选机构，不修改已保存范围。若机构本身停用/启用，配置保持原样（此前已确认）；端侧重新读取时机由对接同事负责，不在本PRD范围。 |
| 端字段清单与缺失键 | 用户提供的每个字段在各影响端的具体位置清单 | 产品范围仅按该清单；关闭产品侧缺字段操作/提示/回退分支。清单之外的代码匹配、缺失键保护和技术验收不由本PRD自行规定。 |
| 未知保存结果 | 管理端写请求发出后响应丢失 | 保存或恢复默认显示“提交结果待核实，请查询提交结果，勿重复提交”，按原请求ID查询；不查询或显示端侧应用状态。查询确认未执行才允许重试原请求，处理中/查询失败继续待核实。
| 授权与故障恢复 | 所有读取、写入校验运营权限与授权机构集合 | 前端禁选只是提示；篡改ID、非授权ID、停用机构ID、非法替换值、同字段重复占用均拒绝整条。超时或重复提交使用请求ID查结果；过期响应不覆盖新状态。原型不接真实认证、不用于生产操作。 |
