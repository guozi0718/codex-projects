# 家校通知 V22 版本说明

用于学校 Web、代理商 Web、运营后台三个固定评审版本。基线项目仍负责各端主菜单和页面框架；本版本只更新“校务管理→家校通知”打开的通知功能。

- 删除后，通知从普通页面消失；隐藏快照保留通知资料、发布设置、对象范围、个人阅读/确认/签字记录、操作人和删除时间，不提供删除状态和恢复入口。
- 新建通知时截止时间默认为空；未设置时继续按发送后30个自然日有效的规则处理。
- Web 一键提醒只针对汇总未读学生及未读教师；学生提醒发送给该学生全部关联家长，已读未确认/未签字不提醒；失败不自动重试。
- 发布状态顺序保持“全部、待发送、已发送、已截止”。
- 教师和家长小程序原型界面、模板资料本轮保持原样。

本版本用于产品评审，状态为修改中、待评审、未定版。真实后台留档、真实消息发送和真实生产名单不由静态原型提供。
