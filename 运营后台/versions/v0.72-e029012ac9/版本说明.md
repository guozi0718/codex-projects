# 运营后台客服管理｜v0.72

状态：第一期修改中、未定版；GitHub Pages静态评审候选。

基线：运营后台 v0.71。历史版本保留。

本版本同步：客服表格铺满内容区且列宽按内容自适应；客服弹窗关闭保留当前机构详情页；客服页移除独立日志入口，统一查看操作日志；姓名和联系电话提示文案统一，联系电话只允许数字且不限制位数。

锁定的客服类型/所属代理商以无边框纯文字回显，不显示必填星号；平台直营不显示所属代理商。
运营机构汇总展示全部代理商，包括客服数量为 0 的代理商。进入该代理商客服详情后保留机构标题；当前机构没有任何客服时，列表空态显示暂无客服信息，新增客服入口保持可用。运营后台可查看、编辑和删除代理商客服。代理商端列表只显示本代理商自行创建的客服，以及平台已关联到本代理商的平台客服；关联的平台客服为只读。
