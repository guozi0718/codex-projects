### 家校通知一期产品需求文档｜全端共通规则

需求范围：第一期新增（产品版本待定）  
文档编号：PRD-FN-20261118-COM  
文档版本：V0.1（修改中）  
文档状态：第一期新增，修改中，未定版  
适用端：学校 Web、代理商 Web、运营后台、教师小程序、家长小程序  
原型状态：Web 三端已发布 GitHub Pages 静态评审版；小程序材料留存，本轮未改、未上传。

#### 1. 需求背景与目标

学校需要通过家校通知向学生及其家长、教师发布纯文本、图文、视频、链接等内容，并按只读、确认收到、签字确认三种查收要求追踪处理状态。运营后台和代理商后台还需要代学校发布；学校 Web 和教师小程序由校内人员发布。

一期目标是让三个 Web 端复用同一通知业务内容，同时各自继续使用所属基线项目的主菜单、页签和外层框架；小程序继续沿用各自留存资料，PRD 记录已确认需求及未完成边界。

本文件是五端 PRD 的共通规则依据。端级菜单、步骤和可用操作以各端 PRD 为准；全端规则若与旧任务记录冲突，以用户最新明确批注为准。

#### 3. 业务对象、角色与归属

##### 3.1 名词与关系

| 名词 | 定义与一期规则 |
|---|---|
| 通知 | 一所学校发布的一条通知，包含标题、封面、内容、发布对象、查收方式、学校名义、发送时间及可选截止时间。 |
| 发布对象 | 选择学生和教师，不直接选择家长；通知到达学生后，该学生关联的家长可接收。 |
| 全班对象 | 选择班级全部学生时，按班级对象保存；有效纳入期内新加入该班的学生自动纳入。 |
| 部分学生对象 | 只选择班级内部分学生时，按具体学生保存；同班新加入学生不自动纳入。 |
| 班级通知副本 | 一个学生若属于多个已选择班级，按班级分别产生通知副本，分别展示和统计；家长端标明相应班级。 |
| 家长状态 | 同一学生的每位关联家长分别保留阅读、确认和签字状态；任一位家长完成当前查收要求，学生汇总为完成。 |
| 教师状态 | 教师逐人记录，按通知要求统计。 |
| 操作快照 | 删除后前端不展示该通知；后端需求保留通知快照、逐人回执、删除操作人和时间。由技术后端实现。 |

##### 3.2 角色与操作范围

| 端/角色 | 可见范围 | 可用操作 | 范围限制 |
|---|---|---|---|
| 学校 Web 用户 | 当前学校通知 | 新增、查看、编辑、删除、预览/打印、阅读统计 | 学校由基线登录上下文确定，不显示选校步骤 |
| 代理商用户 | 有权限代发的学校通知 | 选学校、发布、查看、编辑、删除、预览/打印、统计 | 选校候选必须受代理商现有授权约束；实际权限由后端校验 |
| 运营人员 | 有权限代发的学校通知 | 选学校、发布、查看、编辑、删除、预览/打印、统计 | 运营代发需明确选择目标学校；实际权限由后端校验 |
| 教师 | 本人可访问的学校通知与本人创建内容 | 发布、查看、阅读/确认/签字、查看本人草稿 | 只能发送小程序通知；草稿按教师角色端隔离 |
| 家长 | 当前登录学生的通知 | 查看、阅读、确认、签字 | 不提供切换孩子模块；不显示其他学生通知 |

#### 5. 全端业务规则

##### 5.1 通知内容与附件

| 字段/能力 | 规则 |
|---|---|
| 通知标题 | Web 必填，最多 50 字；Web 不显示 0/50 字数计数。小程序参考原样式，标题长度上限仍为 40 字，若后续确认改动另记。 |
| 封面 | 非必填；字段标签不显示“选填”；与标题输入框内容左侧对齐且不换行。 |
| 通知正文 | 必填；支持纯文本、图文、视频、链接内容；Web 富文本框保留工具栏，正文编辑区样式依当前 V20。 |
| 附件 | PDF、Word、Excel、JPEG/JPG/PNG；最多 9 份，每份不超过 20MB。PDF 与图片可预览，Office 文件下载。 |
| 通知类型 | Web 只发普通通知。教师小程序保留普通通知与美文通知；取消独立链接通知类型和背景音乐。链接仍可作为正文内容。 |
| 美文通知 | 通过内容模块按顺序拼接；可预览并从底部弹层选择背景；返回修改正文或进入发布设置。 |

##### 5.2 发布对象与名单动态规则

1. 发布时分“学生”“教师”两个对象页签；不直接勾选家长。教师按姓名 A-Z 排序，可单选或全选。学生按年级、班级、学生选择；每个班内学生姓名 A-Z 排序。
2. 可全选学生、整年级、整班级或部分学生。整班明确按班级对象保存；整年级的名单存储粒度与未来新增班级规则列入 Q70；部分学生选择按具体学生保存。
3. 全班对象在有效纳入期内随实时名单变化：已发布通知期间新加入该班的学生立即加入通知，并通知其所有关联家长；定时通知发送前新增的学生随原定发送时间接收。
4. 部分学生对象不自动纳入新加入学生。
5. 学生转班或离校后，原已发布通知仍保留在该学生可访问范围；该生可继续阅读、确认或签字并进入统计。发布后不能从该通知中移除该学生；该学生不再因旧班级关系进入后续新通知。
6. 学生复学后，后续新通知按发布时当前在校关系纳入。
7. 新增关联家长仅在通知有效纳入期内进入通知；截止后才关联的家长不进入过期通知。解除关联后，家长仍可处理已经发布给学生的通知。
8. 同一学生同时属于两个已选择班级时，按班级产生独立副本；每份副本独立统计。

##### 5.3 查收方式、状态和统计

| 查收方式 | 家长/教师操作 | 汇总规则 |
|---|---|---|
| 只需阅读查看 | 打开通知即记为已读 | 学生任一家长已读，学生汇总已读；每位家长和教师的个人状态仍分别显示 |
| 需确认收到 | 先阅读，再明确确认 | 学生任一家长确认后，学生汇总完成；其他家长的个人状态保留 |
| 需签字确认 | 阅读后签字 | 学生任一家长签字后，学生汇总完成；显示各家长的签字状态及签字明细 |
| 教师接收 | 与所设通知查收方式相同 | 教师逐人统计 |

阅读统计只展示当前原型已有字段。列表与统计页不增加完成率字段。统计学生行不显示具体年级/班级。统计分页每页 10 人；可以查看每名学生各家长的状态，以及教师个人状态。

没有关联家长的学生在统计中标记为“未关联家长”，并按未完成对象呈现；具体责任人处理路径不在当前原型范围。

##### 5.4 有效期、定时和截止

- 时间显示格式：YYYY-MM-DD HH:mm:ss。
- 定时发送开启后默认时间为次日 09:00:00；定时发送时间必须为未来时间。
- 截止时间默认为空，控件占位文字“请选择”；点击后选择年月日时分秒。
- 如设置明确截止时间，新增学生/家长的自动纳入和确认/签字时限共用此截止点；无截止时间时，自实际发送起 30 个自然日。
- 超过有效时限后，列表显示“已截止”；接收人仍可查看通知及原记录，但不可再确认/签字；禁止一键提醒。
- 过期后不能重新开放；可永久查看和删除。
- “编辑后重新计算时限”的具体起算点与显式截止时间的关系列入待确认 Q66–Q68。未确认前不将其解释为可延长或重开已截止通知。

##### 5.5 修改、删除与一键提醒

- 仅创建人和具备学校管理权限的人可编辑通知，且只能编辑通知内容、封面和学校名义；发布对象不可在发布后移除或调整。提交前由实际权限系统复验。
- 最新可编辑字段口径：通知内容、封面、学校名义。发布对象、查收方式、发布时间、定时发送时间不得编辑。按后续“仅编辑内容、封面和学校名义”口径，截止时间也不作为普通编辑字段；其时限重算规则列入待确认。发布后任一接收人已读、确认或签字，编辑按钮置灰并禁止提交。
- 每次允许编辑时重新核对发布设置字段，避免旧值覆盖；保留修改历史但前端不展示修改日志，也不向接收人发送修改提醒。
- 通知过期后不可编辑；删除永久可用。删除后前端立即消失、不可恢复，不向家长发送消息；后端保存通知快照、逐人状态、操作人和操作时间，清理规则由后端处理。
- 不提供撤回操作。
- 一键提醒只向未读家长和未完成教师发送小程序提醒；提醒按当下个人状态筛选。允许重复提醒。只下发，不显示发送任务或成功/失败状态，不重试；截止后禁用。

#### 6. Web 通用界面需求

##### 6.1 通知列表

| 区域 | 字段/组件 | 展示规则 |
|---|---|---|
| 筛选 | 通知来源、通知标题、发布人、通知类型、查收方式、发布状态、发布时间 | 枚举筛选默认“全部”；通知来源按当前端已有来源枚举，通知类型为普通通知，查收方式为三种已定义方式，发布状态为已发送/待发送/已截止；文本框用“请输入通知标题/请输入发布人”；时间范围保留现有占位 |
| 操作 | 查询、重置 | 与筛选第一行对齐并固定靠右；筛选容器与按钮边界对齐 |
| 新增 | 发布通知 | 筛选区下方靠左；按钮不带加号 |
| 列表 | 来源、标题、发布人、类型、查收方式、发布状态、发布时间及已有统计字段、创建时间、操作 | 每列只承载一个字段；标题左对齐，其余列居中；不显示未实现的完成率 |
| 操作列 | 预览/打印、编辑、删除、阅读统计 | 单行展示；操作列固定，数据列在自身容器中横向滚动并与操作列对齐 |
| 分页 | 页码、每页数量、总数 | 列表底部；统计子页 10 人/页 |

页面不使用双重边框嵌套；使用当前基线框架，不增加非必要提示文案。表格密度、行距、标题、输入框和按钮样式参考运营后台合同管理及用户提供的反馈表单截图。填写内容页的单行输入框与字段标签统一高度、字号、边框和对齐；附件行使用绿色描边“选择文件”按钮，按钮下方显示支持格式、数量和单文件大小说明。通知正文富文本编辑器及工具栏保持 V20 当前尺寸与布局，不改成普通文本框。

阅读统计采用紧凑布局，统计概览、筛选和表格之间保持清晰但较小的垂直间距；减少大块留白，分页固定每页 10 人。

##### 6.2 预览/打印与 PDF

预览/打印为独立页面，显示通知内容及与查收类型匹配的统计明细，不展示发布设置。只显示当前页面打印所需内容；PDF 页面不含预览页顶部栏和“演示说明”。底部“导出 PDF”“关闭”按钮靠右。纸张按 A4，四周采用项目已记录的版心边距：上 37mm、右 26mm、下 35mm、左 28mm。PDF 必须维持该边距；实际文件导出与分页仍需后端/浏览器实现验收。

#### 7. 共通异常与恢复规则

| 场景 | 页面行为 | 数据/状态 |
|---|---|---|
| 页面直接访问但缺少合法通知参数 | 不执行写操作；保留基线菜单可用，给出必要提示 | 不改变通知 |
| 列表或统计读取失败/超时 | 显示读取失败状态并允许重新读取；不得显示成“无记录”或把人数显示成 0 | 不改变通知或统计结果 |
| 学校/地区/教师/学生候选加载失败 | 保留已输入筛选；显示必要失败状态并允许重试；不得把旧学校或旧对象伪装成新筛选结果 | 不扩大授权范围、不改变已保存对象 |
| 学校、对象、标题或内容缺失 | 阻止下一步/提交，保留未提交内容并定位字段 | 不创建通知 |
| 标题超过 50 字或正文为空 | 阻止进入下一步/发布，定位字段；标题不显示实时 0/50 计数 | 不创建通知 |
| 附件数量超过 9、单份大于 20MB 或格式不支持 | 只拒绝不合格的新文件，说明对应限制；其余有效附件继续保留 | 不清空其他有效附件 |
| 定时发送时间已过去 | 阻止保存/发布，要求选未来时间 | 不创建定时任务 |
| 截止时间早于或等于发送时间 | 阻止提交并定位截止时间；定时发送时与计划发送时间比较，即时发送时与当前时间比较 | 不创建通知 |
| 发布/编辑/删除点击后服务端结果未知 | 锁住重复点击；先重新读取目标通知或当前版本，再给出可重试/已完成结果 | 不因超时盲目重复创建或覆盖 |
| 提交时对象、权限或通知版本已变化 | 提交前复验；提示刷新/重新打开，保留可恢复的用户输入 | 不覆盖更新记录 |
| 发布结果未知 | 不盲目重复创建；先按实际记录核验是否已创建 | 避免重复通知 |
| 编辑时发现已有人完成阅读/回执/签字 | 禁止编辑，按钮置灰；提交端也拒绝 | 既有内容与状态不变 |
| 删除确认后成功 | 记录从所有前端立即消失 | 后端快照保留，不展示已删除状态 |
| 提醒接口失败 | 前端不展示发送状态，不重试 | 不改变阅读/回执状态 |
| 文件格式或大小不符 | 阻止添加，并说明支持格式/限制 | 不影响其他已添加附件 |
| PDF 导出失败 | 保留当前预览页，允许用户再次手动导出 | 不修改通知 |

#### 10. 交付边界与已知限制
