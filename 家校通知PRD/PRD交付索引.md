#### 1. 交付内容

本交付包含一份全端共通规则及五份分端 PRD：学校 Web、代理商 Web、运营后台、教师小程序、家长小程序。

六份 PRD 采用用户指定的客服管理代理商端 PRD 框架，逐页面列明入口和用途、字段、默认值、操作、校验、异常表现、结果和后续操作。文档描述产品需求，不下达代码、技术框架或后台实现方式的任务。

- [全端共通规则](家校通知一期产品需求文档-全端共通规则.md)：通知类型和来源、对象范围、时限、查收、编辑、删除、提醒、统计、预览/打印、异常及待确认规则。
- [学校 Web](家校通知一期产品需求文档-学校Web.md)：两步发布、学校内通知展示、列表、编辑、统计、打印和删除。
- [代理商 Web](家校通知一期产品需求文档-代理商Web.md)：选学校、填写通知、发布设置三步代发与管理。
- [运营后台](家校通知一期产品需求文档-运营后台.md)：平台代学校发布和管理通知。
- [教师小程序](家校通知一期产品需求文档-教师小程序.md)：学校通知、我发布、我接收、草稿箱、普通/美文通知和模板。
- [家长小程序](家校通知一期产品需求文档-家长小程序.md)：当前登录学生的通知列表、全部/待办、阅读和回执。
- [原型映射与同步规则](原型映射与同步规则.md)：五端当前主端入口、独立 V25/V26 历史源边界、后续同步方法。
- [文档核对记录](文档核对记录.md)：需求与页面核对结果。
- [原型发布登记](原型发布登记.json)：GitHub 提交号、页面链接、版本和文件校验值。

#### 3. 本轮已落实

- 通知来源统一；家长只接收，不是通知来源。
- 类型统一为普通通知、美文通知；正文链接不是第三种类型。
- Web 新发布为美文通知；Web 可按原权限编辑无任何查收记录且未过期的各端通知；普通通知以单文本内容块编辑，保留原类型。
- 代理商与运营后台代发必须使用学校名义，开关固定开启且不可关闭。
- 代理商和运营后台无草稿；教师小程序草稿保存通知内容和发布设置中已填写的信息，仅教师端可见。
- 学校 Web 可看到同校教师、学校、代理商和平台端发布的所有通知，不因个人或学校名义隐藏；原编辑权限不变。
- 教师、家长小程序当前候选已推送 GitHub；本批 PRD 同步写明图像比例、段首空格、回执按钮和分享权限。

#### 5. V0.8 批注修订记录

- 来源筛选顺序固定为学校端、教师端、平台端、代理商（依系统既有配置顺序）。
- 学校 Web、运营后台来源列单行完整显示；标题单行显示最多10个字，超出以省略号呈现，悬停可看全文；创建时间为“YYYY-MM-DD HH:mm”。
- Web 编辑内容不提供录音入口；离开未保存内容时弹窗统一使用“放弃编辑”、确认文案及“取消/确定”按钮。
- 三端列表操作显示“预览”；预览页标题统一为“通知预览”，不含查收统计，通知内容区独立滚动，PDF只导出通知信息。
- 阅读统计的学生、教师 Tab 均不显示未读提醒按钮；无删除权限时按钮仍显示“删除”并置灰，悬停提示“无权限”。已有人查收与无操作权限时的编辑按钮分别置灰并显示对应提示。
- 代理商列表仅显示本代理商代发记录（同一代理商成员共享），移除通知来源筛选和列表列，增加目标学校及操作人姓名快照；运营后台可查看所有学校和来源，但保留原管理权限；学校 Web 查看发给当前学校的全部来源通知。
- 列表统计中未读、已读均显示数字；已确认和已签字人数只在对应查收方式下显示数字，其他情况显示“--”。

- 学生统计调整：学生统计展示班级汇总 A 页；点击“明细”查看班级学生 B 页。A 页年级/班级筛选级联，B 页只保留状态/学生姓名模糊查询。三端 Web 的指标、空结果、分页、状态联动规则已补入对应 PRD 与共通规则。
- 三端 Web 通知列表的“通知标题”表头居中，标题内容靠左；其他字段内容居中。
- 三端 Web 筛选栏均移除“内容形式”筛选项。
- 学校 Web 在创建时间后增加操作人姓名列，鼠标悬停显示操作角色来源；运营后台在创建时间后增加操作人姓名和角色列；代理商端保留现有操作人姓名快照列。


#### 6. V0.9 发布设置修订记录

- 代理商代发通知的发布对象改为下拉多选，仅允许全体学生、全体教师，可选一项或两项；复制旧通知为新通知时必须重新选对象。
- 学校 Web、代理商 Web、运营后台的 PC 发布设置统一为字段标题与控件同一行，各行控件左缘及高度对齐。
- 本轮仅更新三个 Web 页面和相应产品需求；教师、家长小程序原型及模板资料保留不变。

#### 7. V0.10 本轮修改记录

- 三个 Web 端移除“发布人”筛选；运营后台和代理商端在首位增加目标学校模糊筛选及可见学校候选回显。
- 代理商列表仅展示“预览”“编辑”，不展示“删除”“阅读统计”。
- 三端 Web 的学校名义通知与定时发送均为非必填；学校端默认学校名义并显示学校/登录人快照，运营后台和代理商固定以学校名义代发。
- Web 与小程序通知预览标题均居中并按宽度完整换行。

#### 8. V0.11 普通通知编辑方式

- 学校 Web、代理商 Web、运营后台编辑普通通知时只显示一个文本块；不显示新增内容块入口，也不显示文本块上移、下移、删除按钮。
- 文本内容可修改，保存后保持普通通知类型；美文通知编辑方式不变。
- 教师和家长小程序原型、模板资料不在本轮修改范围内。
