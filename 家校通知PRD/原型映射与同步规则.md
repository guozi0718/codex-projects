#### 2. 当前版本与范围

- 通知功能源为本地任务目录 T-20261123-02 中的版本 V25，GitHub 路径为 家校通知/版本-V25/。
- 三个 Web 菜单仍由学校、代理商、运营后台各自基线项目管理；菜单点击后加载 V25 通知页面，子页面、编辑页、弹窗和统计页继续使用同一通知页面路由。
- 学校菜单入口当前固定到 releases/v0.57；代理商入口使用基线项目根目录，另保留 v0.66 版本；运营后台当前根目录入口重定向到 v0.70-a58c2af5ff。
- 小程序需求写入 PRD，但按用户明确要求，现有小程序原型和模板文件本轮不更改、不发布。

#### 3. 发布与评审状态

V25 已发布到 GitHub 供评审，仍属修改中、未定版。各菜单入口、通知页面直达链接、提交号与源文件校验值以原型发布登记为准。GitHub Pages 是评审原型，不代表真实服务已经上线。

#### 4. 统一口径摘要

通知类型只有普通通知和美文通知。正文内容形式另行区分，链接是正文内容形式。通知来源统一为教师端、学校端、平台（代理商名称）和平台端，家长端只接收、不发布。Web 新发布为美文通知；Web 可在原有权限范围内编辑符合条件的各端通知，已有阅读、确认或签字记录、或已到截止时间时不能编辑。普通通知在 Web 编辑时以单个文本内容块呈现并保留普通通知类型。代理商和运营后台代发时固定使用学校名义，没有草稿功能。学校 Web 显示本校全部通知，发布身份不改变可见范围，编辑权限仍按原规则执行。

#### 5. 待确认事项

Q70：全年级范围之后新建的班级是否加入原通知。
Q71：代发人编辑流程中改选目标学校后，标题、正文、封面、附件如何保留，原已选对象如何清空与确认。

在用户确认前，Q70、Q71 只作为待确认项，不写成已确认口径。
## V25 批注修订映射

三端 Web 菜单仍由各自基线项目持有，菜单配置统一加载家校通知 V25。V25 与 PRD V0.8 同步记录来源排序、列表文本显示、Web编辑入口、统计按钮、删除权限文案、操作人字段呈现及预览打印滚动方式。后续任何页面变更都继续更新三端共用原型与对应 PRD。

### 学生统计 A/B 对应

- 三端 Web 通知页面的“阅读统计”入口先进入 A 页，显示年级、班级、统计进度和明细。点击某班“明细”进入 B 页；B 页保留学生姓名、阅读情况、查收结果、明细列，不再重复显示年级和班级列。
- A 页只保留年级、班级级联筛选；B 页只保留状态、学生姓名模糊筛选。筛选选项、统计数字、完成口径和分页均以三份 Web PRD及全端共通规则第6.6节为准。教师名单统计仍在原教师统计页签中显示。
