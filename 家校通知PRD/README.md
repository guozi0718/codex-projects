### 家校通知一期 PRD

本目录为家校通知一期 PRD 评审包，状态为第一期修改中、待评审、未定版。当前文档批次为 V0.13（Web PRD及共通规则；小程序 PRD 暂保留 V0.10），对应 Web 通知功能源 V25。

六份 PRD 按用户指定的客服管理项目代理商端文档结构编写。分端文档逐页说明入口、展示内容、字段与默认值、操作顺序、校验、异常提示和用户可继续采取的动作；使用产品语言，不包含开发实现指令。

三个 Web 基线菜单目前已接入 V25 通知页面。教师和家长小程序 PRD 记录已确认的需求，原型与模板资料按用户要求保留，本轮不改、不发布。

三个 Web 端列表预览页和发布/编辑预览均显示小程序样式手机边框；列表预览页可导出独立 A4 PDF，PDF 不含手机框及页面控件。完整规则见全端共通规则第6.8节及三个 Web PRD 的预览章节。

当前仍待确认的业务事项为 Q70、Q71，详见[全端共通规则第9节](家校通知一期产品需求文档-全端共通规则.md)。
学生统计改为班级汇总 A 页及班级学生明细 B 页。学生统计口径、筛选级联、空结果、筛选联动、分页和异常场景已写入三份 Web PRD及全端共通规则。


V0.10 同步 Web 目标学校模糊筛选、移除发布人筛选、代理商操作列收敛、发布设置必填口径和通知预览标题样式。此前 V0.9 的代理商对象下拉多选及 PC 发布设置横向排版继续有效。

本轮补充普通通知 Web 编辑规则：固定显示一个文本块，隐藏新增、排序和删除内容块操作。
